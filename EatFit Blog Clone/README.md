# 🍽️ EatFit Blog Clone

A responsive frontend clone of the **EatFit Blog** website built using **HTML5** and **CSS3**. This project recreates the clean and modern design of the EatFit Blog homepage while focusing on responsive layouts, typography, and card-based content sections.

## 📌 Project Overview

The goal of this project was to improve frontend development skills by recreating a real-world website layout. The project includes a navigation bar, logo section, category menu, blog cards, and footer while maintaining a clean and user-friendly interface.

## 🚀 Features

* Responsive webpage layout
* Modern navigation bar
* Blog card design with images and descriptions
* Clean and attractive UI
* Organized page structure
* Footer section
* Mobile-friendly design (if responsive CSS is added)

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design Principles
